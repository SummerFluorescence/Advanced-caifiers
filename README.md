# Advanced-caifiers
Task: Skin lesion classification (7 classes, incl. melanoma) on HAM10000; analysing error patterns, class-imbalance bias and artefact shortcuts (ink, dark corners) with black-box (Phase I) and explanation methods (Phase II). Dataset: https://doi.org/10.7910/DVN/DBW86T
Model: ImageNet-pretrained ResNet-50, fine-tuned on HAM10000 (https://arxiv.org/abs/1512.03385)
