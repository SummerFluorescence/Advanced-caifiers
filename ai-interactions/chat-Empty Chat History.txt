### **Phase 1: Local Input-Space Explanations (Model-Agnostic)**
*Goal: Explain individual predictions by observing how the model’s output changes when parts of the input image are altered.*

1. **LIME (Local Interpretable Model-agnostic Explanations)** *(Lecture 4, Slides 24-33)*
   - **How it works (Black-Box):** The ISIC image is segmented into interpretable components called **superpixels**. The black-box ResNet is queried multiple times with perturbed versions of the image (e.g., specific superpixels are grayed out or masked). 
   - **Output:** A local, interpretable linear surrogate model is fitted to these input-output pairs, highlighting which superpixels (e.g., an irregular border or a dark pigment network) positively or negatively contributed to the "melanoma" vs. "benign" prediction.
   - **Lecture Alignment:** Explicitly covered as a "Local, Model-agnostic" method for image data.

2. **SHAP (Shapley Additive exPlanations)** *(Lecture 4, Slides 35-43)*
   - **How it works (Black-Box):** Based on cooperative game theory. It treats the prediction as a "payout" and the input features (superpixels or image regions) as "players." It queries the black-box model with all possible coalitions of masked features to calculate the exact, fair marginal contribution of each region to the final output probability.
   - **Output:** A visually intuitive force plot or summary plot showing exactly how much each image region pushed the prediction away from the base expected value.
   - **Lecture Alignment:** Highlighted as "Local, Model-agnostic" and "Theoretically grounded," though computationally more expensive than LIME.

*Goal: Build trust by showing what the model has "seen" before, without looking inside its latent space.*

   - **How it works (Black-Box):** Instead of measuring similarity in the model’s internal latent space (which would violate the black-box constraint), we measure similarity purely in the **input domain**. We can use traditional, model-agnostic image similarity metrics (e.g., Structural Similarity Index (SSIM), color histograms, or simple downsampled pixel distance) to find the most visually similar images in the ISIC training set.
   - **Output:** For a given query image, we display the top-$k$ most similar training images alongside their ground-truth labels and the ResNet’s prediction for the query.

We systematically vary *one* of these features across a range while marginalizing over the others, and query the black-box ResNet for the output probability.

### **Implementation: LIME & SHAP for ISIC Images**

*Prerequisites: Ensure you have `torch`, `torchvision`, `lime`, `shap`, `scikit-image`, and `matplotlib` installed.*

```python
import torch
import torchvision.transforms as transforms
import torchvision.models as models
from PIL import Image
import numpy as np
import matplotlib.pyplot as plt
import shap
from lime import lime_image
from skimage.segmentation import mark_boundaries

# =========================================================================
# 1. SETUP THE BLACK-BOX MODEL
# =========================================================================
# In your actual project, load your ISIC-trained ResNet here. 
# For this demonstration, we use a pre-trained ImageNet ResNet50.
model = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)
model.eval()

# Preprocessing pipeline (must exactly match the model's training)
preprocess = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

# =========================================================================
# 2. DEFINE THE STRICT BLACK-BOX PREDICTION FUNCTION
# =========================================================================
# Both LIME and SHAP will ONLY interact with this function. 
# It takes unnormalized numpy images and returns softmax probabilities.
def black_box_predict(images):
    """
    images: numpy array of shape (N, H, W, C) with values in [0, 255]
    returns: numpy array of shape (N, num_classes) with softmax probabilities
    """
    tensor_images = []
    for img in images:
        # Convert numpy array to PIL Image, then apply training preprocessing
        pil_img = Image.fromarray(np.uint8(img))
        tensor_img = preprocess(pil_img)
        tensor_images.append(tensor_img)
    
    batch = torch.stack(tensor_images)
    
    # Forward pass (No internal gradients accessed)
    with torch.no_grad():
        outputs = model(batch)
        probs = torch.nn.functional.softmax(outputs, dim=1)
        
    return probs.numpy()

# =========================================================================
# 3. LOAD AN ISIC IMAGE
# =========================================================================
# Replace 'isic_sample.jpg' with your actual ISIC dataset image path
image_path = 'isic_sample.jpg' 
try:
    original_image = np.array(Image.open(image_path).convert('RGB'))
except FileNotFoundError:
    print(f"Image not found at {image_path}. Using a dummy image for demonstration.")
    original_image = np.random.randint(0, 255, (224, 224, 3), dtype=np.uint8)

# =========================================================================
# 4. APPLY LIME (Local Interpretable Model-agnostic Explanations)
# =========================================================================
print("Running LIME...")
lime_explainer = lime_image.LimeImageExplainer()
lime_explanation = lime_explainer.explain_instance(
    original_image, 
    black_box_predict, 
    top_labels=3,       # Show explanations for top 3 predicted classes
    hide_color=0,       # Color to use when masking superpixels (0 = black)
    num_samples=1000    # Number of perturbed superpixel images to query the black-box
)

# Visualize LIME
top_class_lime = lime_explanation.top_labels[0]
temp, mask = lime_explanation.get_image_and_mask(
    top_class_lime, 
    positive_only=True, # Only highlight regions that push the prediction UP
    num_features=10,    # Number of superpixels to highlight
    hide_rest=False     # Keep the rest of the image visible for context
)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 6))
ax1.imshow(original_image)
ax1.set_title("Original ISIC Image")
ax1.axis('off')

# Draw red boundaries around the influential superpixels
ax2.imshow(mark_boundaries(temp, mask, color=(1, 0, 0))) 
ax2.set_title(f"LIME Explanation (Top Class: {top_class_lime})")
ax2.axis('off')
plt.tight_layout()
plt.show()

# =========================================================================
# 5. APPLY SHAP (Shapley Additive exPlanations)
# =========================================================================
print("Running SHAP (This may take a minute due to computational cost)...")

# SHAP's Image masker automatically handles superpixel segmentation and perturbation
masker = shap.maskers.Image("blur(64,64)", original_image.shape)

# Create the explainer. 
# NOTE: Replace the output_names list with your actual ISIC class names 
# (e.g., ["Melanoma", "Nevus", "BCC", "AKIEC", ...]) for better interpretability!
num_classes = 1000 # Change to your actual number of ISIC classes
class_names = [f"Class_{i}" for i in range(num_classes)] 

shap_explainer = shap.Explainer(
    black_box_predict, 
    masker, 
    output_names=class_names
)

# Explain the image. max_evals controls the number of perturbed samples (computation time)
shap_values = shap_explainer(original_image, max_evals=500)

# Visualize SHAP
# SHAP's image plot shows red for regions that increase the probability, 
# and blue for regions that decrease it.
plt.figure(figsize=(10, 5))
shap.plots.image(shap_values)
plt.show()
```

### ASSISTANT
This is a very common PyTorch checkpoint loading issue! 

The error happens because your `best.pt` file is not just a simple dictionary of weights (`state_dict`). Instead, it is a **full training checkpoint** that contains several pieces of information, including the actual model weights, the epoch number, training metrics, and—most importantly for us—the **class names**.

Here is how the checkpoint dictionary is structured:
* `"model"`: The actual `state_dict` (the weights we need).
* `"epoch"`: The epoch number when the model was saved.
* `"metrics"`: The validation metrics (like accuracy or loss).
* `"classes"`: The list of class names your model was trained on!

### ASSISTANT
This is a classic "gotcha" with SHAP when working with images! 

### **Why this error happens:**
When you pass a 3D NumPy array of shape `(224, 224, 3)` to `shap_explainer()`, SHAP gets confused. Because SHAP is originally designed for tabular data, it assumes the **first dimension** of any array is the **batch size**. 
Therefore, SHAP thinks you are passing a batch of **224 images**, each with a shape of `(224, 3)`. It then tries to explain the first "image" (which is just a 1D slice of shape `(224, 3)`), and the Image Masker crashes because it expects `(224, 224, 3)`.

### **The Fix:**
We just need to explicitly tell SHAP that this is a **batch of 1 image** by adding a batch dimension, turning the shape from `(224, 224, 3)` into `(1, 224, 224, 3)`.

Instead of tabular features, we will use the **image artefact scores** defined in your reference notebook (`dark_corner`, `ink`, `hair`, `brightness`). We will query the black-box model and plot how the average probability of "Melanoma" changes as these artefact scores increase.

Here is the complete, standalone Python code to generate these **Black-Box PDPs**:

```python
import cv2
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from PIL import Image
import torch
import torchvision.transforms as transforms
import torchvision.models as models
from pathlib import Path
import time

# =========================================================================
# 1. SETUP & LOAD MODEL (Matching your notebook exactly)
# =========================================================================
CLASSES = ["akiec", "bcc", "bkl", "df", "mel", "nv", "vasc"]
C2I = {c: i for i, c in enumerate(CLASSES)}
MALIGNANT = ["akiec", "bcc", "mel"]
MEAN, STD = [0.485, 0.456, 0.406], [0.229, 0.224, 0.225]
IMG_SIZE = 224

OUT_DIR = Path(r"C:\Users\siria\Downloads\VisAI")
CKPT_DIR = OUT_DIR / "checkpoints"
pred_all = pd.read_csv(OUT_DIR / "predictions_all.csv")
test = pred_all[pred_all['split'] == 'test'].reset_index(drop=True)

# Load Model
def build_model():
    m = models.resnet50(weights=None)
    m.fc = torch.nn.Linear(m.fc.in_features, len(CLASSES))
    return m

model = build_model()
state = torch.load(CKPT_DIR / "best.pt", map_location="cpu")
model.load_state_dict(state["model"])
model.eval()

EVAL_TF = transforms.Compose([
    transforms.Resize((IMG_SIZE, IMG_SIZE)),
    transforms.ToTensor(), 
    transforms.Normalize(MEAN, STD)
])

@torch.no_grad()
def black_box_predict_arrays(imgs):
    """Strict black-box wrapper for a list of numpy images."""
    out = []
    for im in imgs:
        pil_img = Image.fromarray(np.uint8(im))
        x = EVAL_TF(pil_img).unsqueeze(0)
        probs = torch.softmax(model(x).float(), 1).cpu().numpy()
        out.append(probs[0])
    return np.array(out)

# =========================================================================
# 2. COMPUTE IMAGE ARTEFACT SCORES (From Notebook Section 3)
# =========================================================================
# We will compute these for a random sample of the test set to save time, 
# or the whole test set if you have the patience (approx 2-3 mins for 2000 images).
print("Computing image artefact scores...")
sample_test = test.sample(n=1000, random_state=42) # Sample 1000 for speed

def get_image_scores(image_id):
    img_path = OUT_DIR / "dataset" / f"{image_id}.jpg"
    if not img_path.exists(): return None
    img = np.array(Image.open(img_path).convert("RGB").resize((IMG_SIZE, IMG_SIZE)))
    
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY).astype(np.float32)
    h, w = gray.shape; c = int(0.12 * min(h, w))
    corners = np.concatenate([gray[:c, :c].ravel(), gray[:c, -c:].ravel(),
                              gray[-c:, :c].ravel(), gray[-c:, -c:].ravel()])
    dark_corner = float(np.clip(1 - corners.mean() / (np.median(gray) + 1e-6), 0, 1))
    
    hsv = cv2.cvtColor(img, cv2.COLOR_RGB2HSV)
    violet = (hsv[..., 0] >= 125) & (hsv[..., 0] <= 165) & (hsv[..., 1] > 60) & (hsv[..., 2] > 40)
    ink = float(violet.sum() / violet.size) # Simplified ink score for speed
    
    blackhat = cv2.morphologyEx(gray.astype(np.uint8), cv2.MORPH_BLACKHAT,
                                cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (9, 9)))
    hair = float((blackhat > 18).mean())
    
    return dict(dark_corner=dark_corner, ink=ink, hair=hair)

scores = []
valid_ids = []
for idx, row in sample_test.iterrows():
    s = get_image_scores(row['image_id'])
    if s:
        scores.append(s)
        valid_ids.append(row['image_id'])

scores_df = pd.DataFrame(scores, index=valid_ids)
print(f"✅ Computed scores for {len(scores_df)} images.")

# =========================================================================
# 3. QUERY BLACK-BOX & GENERATE PARTIAL DEPENDENCE PLOTS (PDP)
# =========================================================================
print("Querying black-box model for PDP...")
# Get predictions for our sampled images
imgs_to_predict = []
for img_id in valid_ids:
    img_path = OUT_DIR / "dataset" / f"{img_id}.jpg"
    imgs_to_predict.append(np.array(Image.open(img_path).convert("RGB").resize((IMG_SIZE, IMG_SIZE))))

probs = black_box_predict_arrays(imgs_to_predict)
scores_df['p_malignant'] = probs[:, [C2I[c] for c in MALIGNANT]].sum(axis=1)

# =========================================================================
# 4. PLOTTING THE PDP (Lecture 4: Global, Model-Agnostic)
# =========================================================================
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

for ax, feature in zip(axes, ['dark_corner', 'ink', 'hair']):
    # Bin the continuous feature into quartiles to see the marginal effect
    scores_df['bin'] = pd.qcut(scores_df[feature], q=4, labels=['Q1 (Low)', 'Q2', 'Q3', 'Q4 (High)'], duplicates='drop')
    
    # Calculate mean P(malignant) for each bin (This is the core of PDP)
    pdp_data = scores_df.groupby('bin', observed=True)['p_malignant'].mean()
    
    ax.bar(pdp_data.index, pdp_data.values, color='#2a78d6', edgecolor='white')
    ax.set_title(f"PDP: Effect of '{feature}'\non P(Malignant)", fontsize=12)
    ax.set_ylabel("Mean P(Malignant)")
    ax.set_xlabel(f"{feature} Quartile")
    ax.set_ylim(0, max(pdp_data.values) * 1.2)
    
    # Add value labels on top of bars
    for i, v in enumerate(pdp_data.values):
        ax.text(i, v + 0.01, f"{v:.3f}", ha='center', fontweight='bold')

plt.suptitle("Global Black-Box Analysis: Do Artefacts Systematically Shift Predictions?", fontsize=14, y=1.05)
plt.tight_layout()
plt.show()
```

2. **Black-Box Constraint:** We only used the input images, computed simple pixel metrics (no neural networks involved), and queried the model's final softmax probabilities.
3. **Depth of Understanding:** This plot directly answers the "Why?" If the model is over-confident on benign lesions, this PDP will show you if "ink" or "dark corners" are the root cause of that over-confidence.

### ASSISTANT
Based on your lecture notes (specifically **Lecture 4: Visual Explanation Techniques I**), here is a clear, academic explanation of **LIME** and **SHAP**, tailored to your black-box ResNet project.

Both techniques fall under the category of **Local, Model-agnostic** explanations. This means they do not look inside the neural network (no gradients or weights); instead, they treat the model as a black box and only observe how changes in the *input* affect the *output* for a single, specific prediction.

---

### **1. LIME (Local Interpretable Model-agnostic Explanations)**
*(Lecture 4, Slides 24–34)*

* **The Core Idea:** LIME operates on the principle of a **Local Surrogate Model**. While a deep neural network is globally complex and non-linear, its behavior can be approximated by a simple, interpretable model (like a linear regression) *locally* around a specific data point.
* **How it Works for Images:**
  1. **Segmentation:** The input image is divided into interpretable components called **superpixels** (groups of similar pixels), rather than individual pixels.
  2. **Perturbation:** LIME generates hundreds of new, perturbed versions of the image by randomly "turning off" (masking/graying out) different combinations of these superpixels.
  3. **Black-Box Querying:** Each perturbed image is passed through your ResNet to get a new prediction probability.
  4. **Local Fitting:** LIME fits a simple, weighted linear model to these input-output pairs. The weights are based on proximity: perturbed images that look more like the original image are given higher weight. The resulting linear coefficients tell us which superpixels positively or negatively contributed to the specific prediction.
* **Advantages:** Fast to compute, highly intuitive, and works across different data types (images, text, tabular).
* **Disadvantages:** The results can be unstable depending on how the "neighborhood" of perturbations is sampled, and it can sometimes be fooled by adversarial perturbations.

---

### **2. SHAP (Shapley Additive exPlanations)**
*(Lecture 4, Slides 35–43)*

* **The Core Idea:** SHAP is rooted in **Cooperative Game Theory** (developed by Lloyd Shapley, who won the Nobel Prize in Economics in 2012). It treats the model's final prediction as a "payout" and the input features (e.g., superpixels) as "players" in a coalition game. The goal is to find the *fair* distribution of this payout among the players.
* **How it Works:** 
  To determine the exact contribution of a single superpixel, SHAP calculates its **marginal contribution** across *all possible combinations* (coalitions) of other superpixels being present or absent. 
  *For example:* How much does the "irregular border" superpixel increase the "Melanoma" probability when added to a coalition that already contains the "dark pigment" superpixel, versus a coalition that does not? SHAP averages these marginal effects over all possible coalitions.
* **Advantages:** It is the *only* method that is mathematically guaranteed to be **fairly distributed** and consistent (it satisfies specific axioms like efficiency, symmetry, and additivity). It provides a unified, theoretically grounded framework.
* **Disadvantages:** It is **computationally expensive**. Calculating exact Shapley values requires evaluating the model on $2^M$ possible coalitions (where $M$ is the number of features/superpixels). In practice, algorithms like `PartitionExplainer` or `KernelSHAP` are used to approximate this, but it still takes significantly longer than LIME.

---

### **Why Use Both for Your ISIC Project?**

In your Phase I (Black-Box) analysis, using both provides a powerful, complementary narrative for your homework report:

1. **LIME** gives you a quick, intuitive visual check. You can rapidly generate explanations for multiple images to spot obvious patterns (e.g., "Wait, is the model consistently highlighting the black ruler in the corner?").
2. **SHAP** provides the rigorous, mathematically sound validation. When you present a finding in your report (e.g., "The model relies on ink artifacts to predict Melanoma"), you can back it up with SHAP values, proving that this isn't just a quirk of LIME's local sampling, but a robust, fairly attributed feature contribution.

```python
def blur_dark_crust(img, percentile=5):
    """

    """
    out = img.copy()

    # Find the threshold for the darkest X% of pixels
    threshold = np.percentile(gray, percentile)
    
    # Create a mask of the dark pixels
    mask = (gray <= threshold).astype(np.uint8) * 255
    
    # Dilate the mask slightly to blur the edges of the crust too
    kernel = np.ones((15, 15), np.uint8)
```

### **Method 2: The Exact Ground Truth (ISIC API)**
If your professor asks, *"But `dx_type` isn't the exact hospital name,"* you can query the original ISIC Archive API. The API returns JSON metadata that includes the exact **`meta.acquisition.device`** (e.g., "DermLite DL4", "Canon EOS 20Da") and **`meta.acquisition.source`**.

*Note: The ISIC API is slow. Do not query all 10,000 images. Query a random sample of 500 images to map the devices, then merge it back.*

```python
import requests
import time
import numpy as np

# Sample 500 images from the test set to query the API
sample_ids = test['image_id'].sample(n=500, random_state=42).tolist()

api_data = []
print(f"🌐 Querying ISIC API for {len(sample_ids)} images...")

for i, img_id in enumerate(sample_ids):
    url = f"https://isic-archive.com/api/v1/image/{img_id}"
    try:
        response = requests.get(url, timeout=10)
        if response.status_code == 200:
            data = response.json()
            # Extract device and source from the nested JSON
            device = data.get('meta', {}).get('acquisition', {}).get('device', 'Unknown')
            source = data.get('meta', {}).get('acquisition', {}).get('source', 'Unknown')
            api_data.append({'image_id': img_id, 'device': device, 'source': source})
        else:
            api_data.append({'image_id': img_id, 'device': 'Error', 'source': 'Error'})
    except Exception as e:
        api_data.append({'image_id': img_id, 'device': 'Timeout', 'source': 'Timeout'})
        
    # Progress and polite rate limiting
    if (i + 1) % 50 == 0:
        print(f"Progress: {i+1}/{len(sample_ids)}")
    time.sleep(0.1) 

# Convert to DataFrame and merge with your test set
api_df = pd.DataFrame(api_data)
test_with_devices = test.merge(api_df, on='image_id', how='left')

# Check the most common devices in your sample
print("\n🔍 Most common dermatoscope devices in sample:")
print(test_with_devices['device'].value_counts().head(10))
```

### ASSISTANT
This error happens because of how pandas handles the `agg()` function. 

In pandas, any function you pass to `agg()` **must return a single, aggregated number** (like a mean, sum, or count) for each group. 

The lambda function you used for `avg_entropy` was: `lambda x: 1 - x`. 
Because `x` is the entire list of confidence scores for that lab, `1 - x` returns a whole list of numbers back, not a single average. Pandas crashes because it doesn't know how to put a list into a single row of your summary table.

### **The Fix**
We just need to tell the lambda function to calculate the **mean** of that result. 

Replace **Step 2** in your code with this corrected version:

Since we are strictly in the **Black-Box Phase (Section 8 of your notebook: Synthetic Edge Cases)**, applying these normalizations is a perfect way to test if the model is relying on environmental shortcuts rather than true dermatological features.

Here are the best normalizations to test, categorized by the specific "shortcut" they remove:

---

### **1. Per-Image Z-Score Standardization (Removes Global Brightness & Contrast)**
* **The Shortcut it Tests:** Does the model associate "dark images" with one lab and "bright images" with another? 
* **How it works:** It subtracts the mean and divides by the standard deviation *for each individual image*. This forces every image to have the exact same global brightness and contrast distribution, completely neutralizing the differences between labs (like the isolated `vidir_molemax` cluster in your UMAP).
* **Why it preserves the lesion:** The *relative* differences between pixels (the texture and edges of the lesion) remain perfectly intact.

### **2. CLAHE - Contrast Limited Adaptive Histogram Equalization (Enhances Local Texture)**
* **The Shortcut it Tests:** Does the model fail on images with poor local contrast?
* **How it works:** Instead of stretching the contrast of the whole image (which can blow out highlights), CLAHE divides the image into small tiles and equalizes the contrast locally. 
* **Why it preserves the lesion:** It actually *enhances* the diagnostic features (pigment networks, streaks) without altering the global color balance. It is heavily used in medical imaging.

### **3. White Patch Retinex (Alternative to Gray World)**
* **The Shortcut it Tests:** Color cast bias (e.g., one dermatoscope makes everything look slightly yellow).
* **How it works:** Gray World assumes the *average* color of the scene is gray. White Patch assumes the *brightest* pixel in the scene is pure white. It scales the R, G, and B channels so that their maximum values align.
* **Why it preserves the lesion:** It corrects the global illuminant without changing the local color ratios of the lesion itself.

### **4. Vignette / Dark Corner Correction (Removes `dark_corner` bias)**
* **The Shortcut it Tests:** Your notebook explicitly calculates a `dark_corner` score. Does the model use the dark edges of the dermatoscope view as a shortcut?
* **How it works:** We apply a radial gradient to mathematically brighten the corners to match the center of the image.

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

# =========================================================================
# 1. DEFINE THE NORMALIZATIONS
# =========================================================================
def normalize_zscore(img):
    """Per-image Z-score: Removes global brightness and contrast differences."""
    img_float = img.astype(np.float32)
    # Normalize per channel
    for c in range(3):
        mean = img_float[..., c].mean()
        std = img_float[..., c].std() + 1e-6
        img_float[..., c] = (img_float[..., c] - mean) / std
    # Scale back to 0-255 for the model
    return np.clip((img_float - img_float.min()) / (img_float.max() - img_float.min() + 1e-6) * 255, 0, 255).astype(np.uint8)

def normalize_clahe(img):
    """CLAHE: Enhances local contrast without changing global color."""
    # Convert to LAB color space to apply CLAHE only to the L (Lightness) channel
    lab = cv2.cvtColor(img, cv2.COLOR_RGB2LAB)
    l, a, b = cv2.split(lab)
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    cl = clahe.apply(l)
    merged = cv2.merge((cl, a, b))
    return cv2.cvtColor(merged, cv2.COLOR_LAB2RGB)

def normalize_white_patch(img):
    """White Patch Retinex: Assumes brightest pixel is white."""
    img_float = img.astype(np.float32)
    # Find the 99th percentile to avoid noise/outliers
    r_max = np.percentile(img_float[..., 0], 99)
    g_max = np.percentile(img_float[..., 1], 99)
    b_max = np.percentile(img_float[..., 2], 99)
    
    img_float[..., 0] = img_float[..., 0] * (255.0 / r_max)
    img_float[..., 1] = img_float[..., 1] * (255.0 / g_max)
    img_float[..., 2] = img_float[..., 2] * (255.0 / b_max)
    return np.clip(img_float, 0, 255).astype(np.uint8)

def normalize_vignette(img):
    """Brightens the corners to remove the dark_corner artefact."""
    h, w = img.shape[:2]
    # Create a radial gradient mask (1.0 in center, 1.5 at corners)
    X, Y = np.meshgrid(np.linspace(-1, 1, w), np.linspace(-1, 1, h))
    dist = np.sqrt(X**2 + Y**2)
    # Scale so corners get brighter
    correction = 1.0 + (dist ** 2) * 0.4 
    
    img_float = img.astype(np.float32)
    corrected = img_float * correction[..., np.newaxis]
    return np.clip(corrected, 0, 255).astype(np.uint8)
```

```python
    return cv2.cvtColor(merged, cv2.COLOR_LAB2RGB)

def normalize_white_patch(img):
    img_float = img.astype(np.float32)
    r_max = np.percentile(img_float[..., 0], 99)
    g_max = np.percentile(img_float[..., 1], 99)
    b_max = np.percentile(img_float[..., 2], 99)
    img_float[..., 0] = img_float[..., 0] * (255.0 / r_max)
    img_float[..., 1] = img_float[..., 1] * (255.0 / g_max)
    img_float[..., 2] = img_float[..., 2] * (255.0 / b_max)
    return np.clip(img_float, 0, 255).astype(np.uint8)

def normalize_vignette(img):
    h, w = img.shape[:2]
    X, Y = np.meshgrid(np.linspace(-1, 1, w), np.linspace(-1, 1, h))
    dist = np.sqrt(X**2 + Y**2)
    correction = 1.0 + (dist ** 2) * 0.4 
    img_float = img.astype(np.float32)
    corrected = img_float * correction[..., np.newaxis]
    return np.clip(corrected, 0, 255).astype(np.uint8)

def get_pixel_features(img):
    """Extracts the 5 features used for clustering."""
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY).astype(np.float32)
    brightness = float(gray.mean() / 255.0)
    contrast = float(gray.std() / 255.0)
    avg_r, avg_g, avg_b = img.mean(axis=(0, 1)) / 255.0
    return [brightness, contrast, avg_r, avg_g, avg_b]
```

### **How to Interpret the Results for Your Report:**

Look at the **"Original"** plot first. You will likely see the green cluster (`vidir_molemax`) isolated at the bottom, just like in your previous analysis. 

Now, look at the other four plots:

1. **If the green cluster moves UP and merges with the blue/purple clusters in the "Z-Score" plot:**
   * **Conclusion:** The domain shift was caused by **global brightness and contrast differences**. The `vidir_molemax` dermatoscope simply produced darker or lower-contrast images, and the model was failing because it wasn't used to that lighting. Z-Score fixed it.

2. **If the green cluster merges in the "White Patch" plot:**
   * **Conclusion:** The domain shift was caused by a **color cast** (e.g., the dermatoscope's lightbulb made all images look slightly yellow or red). White Patch corrected the illuminant, removing the lab's visual fingerprint.

3. **If the green cluster merges in the "Vignette" plot:**
   * **Conclusion:** The lab had a severe **dark corner artefact** that the model was using as a shortcut.

4. **If the green cluster REMAINS isolated in ALL plots:**
   * **Conclusion:** The difference between the labs is not just global lighting or color. It is likely due to **local texture differences** (e.g., one dermatoscope has higher optical resolution, making pigment networks look sharper) or the **lesions themselves** are fundamentally different across labs (e.g., one lab only photographs severe cases).
